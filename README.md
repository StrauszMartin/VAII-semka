Top Dance Žilina – informačný systém

Semestrálna práca 

Táto webová aplikácia slúži na lepšiu komunikáciu trénerov s klubistami. 
Bežný prihlásený používateľ može prehliadať oznamy alebo preferované súťaže.
Prihlásený tréner vie  tieto oznamy a preferované súťaže pridávať, upravovať a mazať.

---

### Postup inštalácie
1. Stiahnutie XAMPP
2. Spustenie Apache a MySQL
3. Naklonovanie repozitára do lubovolného IDE 
4. spustit loclahost/phpmyadmin
5. importnut databázu z foldra DATABAZA
6. Vloženie Projct Foldra do xampp/htdocs
7. Spustenie aplikacie pomocou localhost/*názov project foldru*

Ak nemáte účet → zaregistrovať sa
Ak máte účet → prihlásiť sa
